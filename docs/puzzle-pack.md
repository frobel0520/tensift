# Tensift Pilot Puzzle Pack v1

Status: Draft for blind playtesting  
Language: English  
Format: 10 familiar items, four unlabeled groups with capacities 1 / 2 / 3 / 4

## Editorial standard

- Items should be recognizable without specialist knowledge.
- Every puzzle uses one classification dimension across all four rows.
- Group membership should be objective under the wording used in the reveal.
- The 1-item row should become defensible once the rule is understood.
- A puzzle must be blind-tested before publication; familiarity is not proof of uniqueness.

## Recommended pilot order

1. Countries
2. Animals — class
3. Fruits — letter count
4. Cities
5. Vehicles
6. Musical Instruments
7. Animals — legs
8. Landmarks
9. Sports
10. Classic Works

This order moves from concrete membership toward less expected lenses while keeping the items familiar.

## Gate before publishing any puzzle

- At least three people complete it without author guidance.
- No tester finds a second full 1 / 2 / 3 / 4 solution.
- At least two testers describe the reveal as fair.
- Any disputed item is replaced, not defended through a long explanation.
